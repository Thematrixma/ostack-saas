==========================================================
بوصلة الشخصية - موقع اختبار وتحليل الشخصية بنموذج DISC
==========================================================

نظرة عامة
----------------------------------------------------------
موقع عربي RTL كامل يقدم اختبار DISC للأفراد، مبني بالكامل
بـ HTML و CSS و JavaScript بدون أي Backend. يعمل مباشرة عند
فتح index.html في المتصفح.

هذا الموقع للتطوير الذاتي وفهم السلوك فقط، وليس تشخيصًا
نفسيًا أو طبيًا.

----------------------------------------------------------
الملفات
----------------------------------------------------------
index.html            الصفحة الرئيسية: العرض، الباقات، نموذج التقرير
register.html          صفحة تسجيل بيانات العميل بعد اختيار الباقة
payment.html            صفحة دفع تجريبية (جاهزة للربط لاحقًا)
test.html               اختبار DISC (48 سؤالًا)
report.html              التقرير النهائي حسب الباقة المختارة
report-sample.html        نموذج تقرير ثابت للعرض على الزوار
style.css                التنسيقات الكاملة للموقع (RTL + متجاوب + طباعة)
app.js                   كل البيانات: الباقات، الأسئلة، محتوى التقارير، الأدوات
GOOGLE_SHEETS_SETUP.txt   شرح ربط الموقع بـ Google Sheets
README.txt                هذا الملف

----------------------------------------------------------
رحلة المستخدم
----------------------------------------------------------
1. index.html      → يختار المستخدم الباقة
2. register.html    → يدخل بياناته (تُحفظ في localStorage)
3. payment.html      → يكمل دفعًا تجريبيًا
4. test.html          → يؤدي اختبار DISC (48 سؤالًا)
5. report.html         → يحصل على تقريره الكامل حسب باقته،
                          مع إمكانية الطباعة كـ PDF والإرسال بالبريد

----------------------------------------------------------
التخزين المحلي (localStorage)
----------------------------------------------------------
يستخدم الموقع localStorage لحفظ:
- bawsala_selected_package : الباقة المختارة
- bawsala_customer          : بيانات العميل
- bawsala_payment_status     : حالة الدفع التجريبية
- bawsala_test_answers        : إجابات الاختبار
- bawsala_test_result          : النتيجة النهائية المحسوبة

----------------------------------------------------------
كيفية التعديل
----------------------------------------------------------
كل المحتوى القابل للتعديل موجود في app.js:

- PACKAGES        لتعديل الباقات والأسعار والمزايا
- QUESTIONS         لتعديل أو إضافة أسئلة الاختبار (الدالة q())
- PATTERN_CONTENT     لتعديل محتوى تحليل كل نمط (D / I / S / C)
- DISC_INFO            لتعديل أسماء وألوان الأنماط
- get7DayPlan / get30DayPlan  لتعديل خطط التحسين
- TWELVE_TRAITS         لتعديل قائمة السمات السلوكية الـ 12

----------------------------------------------------------
الربط بخدمات خارجية (لاحقًا)
----------------------------------------------------------
1. Google Sheets:
   راجع GOOGLE_SHEETS_SETUP.txt واملأ المتغير
   GOOGLE_SHEETS_WEBAPP_URL في أعلى app.js

2. خدمة البريد (EmailJS أو غيرها):
   املأ المتغيرات EMAILJS_SERVICE_ID و EMAILJS_TEMPLATE_ID
   و EMAILJS_PUBLIC_KEY في app.js، ثم عدّل دالة sendReportByEmail()
   لاستخدام مكتبة EmailJS الفعلية بدل التنبيه التجريبي الحالي.

3. بوابة الدفع (Moyasar / Tap / Paylink):
   في payment.html عند زر "إتمام الدفع"، استبدل منطق الدفع
   التجريبي الحالي بطلب فعلي لبوابة الدفع المختارة، ثم وجّه
   المستخدم لصفحة الاختبار فقط بعد تأكيد الدفع الناجح من البوابة.

----------------------------------------------------------
تحميل التقرير PDF
----------------------------------------------------------
يتم عبر زر "تحميل التقرير PDF" الذي يستدعي window.print()
مباشرة. تنسيق الطباعة مضبوط مسبقًا في style.css (وسم @media print)
بحيث يظهر التقرير منظمًا بصيغة A4 مع إخفاء الهيدر والفوتر والأزرار.
